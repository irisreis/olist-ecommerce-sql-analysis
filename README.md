# Análise de Dados de E-commerce | Olist

## Sobre o projeto

Este projeto tem como objetivo explorar dados de um e-commerce brasileiro utilizando SQL e PostgreSQL, buscando compreender o comportamento das vendas, dos clientes, dos pagamentos e das entregas.

O conjunto de dados utilizado é o **Brazilian E-Commerce Public Dataset by Olist**, disponibilizado no Kaggle.

## Tecnologias utilizadas

- PostgreSQL
- SQL
- DBeaver
- Git e GitHub

## Análises desenvolvidas

- Distribuição dos pedidos por status
- Faturamento por categoria de produto
- Análise de vendas por estado
- Métodos de pagamento mais utilizados
- Identificação de clientes com maior volume de compras
- Classificação de vendedores por faturamento
- Análise de atrasos nas entregas

## Conceitos SQL aplicados

JOIN, GROUP BY, funções de agregação, CASE WHEN, CTEs, funções de janela e RANK().

## Fonte dos dados

[Brazilian E-Commerce Public Dataset by Olist — Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
